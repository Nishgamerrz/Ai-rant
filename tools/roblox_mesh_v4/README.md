# Roblox FileMesh v4 reader

The `reader.py` and `model.py` modules are adapted from the MIT-licensed
[Roblox Mesh Importer](https://github.com/Dimitriuses/Roblox-Mesh-Importer)
project by Dimitriuses. The original MIT license is included in this directory.

This minimal copy is used only to decode public Roblox `.mesh` v4 geometry for
the automated avatar conversion pipeline. It does not include Blender code or
any third-party Roblox assets.
